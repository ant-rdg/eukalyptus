# Code de conduite

*English summary at the bottom.*

## Notre engagement

Nous voulons que participer à Eukalyptus (issues, discussions, pull requests) soit une expérience respectueuse et utile pour tout le
monde, quels que soient l'âge, le handicap, l'origine, l'identité, l'expérience, la nationalité, l'apparence, la religion ou
l'orientation de chacun. Nous nous engageons à agir et à interagir de manière à construire une communauté ouverte, accueillante et
sereine.

## Ce que nous attendons

Les comportements qui contribuent à un bon climat :

- se montrer accueillant et patient, surtout avec les débutants ;
- respecter les points de vue et les expériences différentes ;
- donner et accepter les critiques constructives avec bienveillance ;
- reconnaître ses erreurs, s'en excuser, et en tirer des leçons ;
- se concentrer sur ce qui est bon pour la communauté et pour le projet.

Les comportements qui ne sont pas acceptables :

- les propos ou images à caractère sexuel, et toute avance importune ;
- les insultes, les attaques personnelles, les commentaires désobligeants ou politiques qui visent une personne ;
- le harcèlement, en public ou en privé ;
- publier les informations privées d'autrui (adresse, e-mail, identifiants…) sans son accord ;
- la publicité, la promotion ou les messages répétés hors sujet ;
- toute autre conduite qui serait raisonnablement jugée inappropriée dans un cadre professionnel.

## Application

L'auteur du projet est responsable de l'application de ce code de conduite. Il peut modifier, masquer ou supprimer tout commentaire,
issue, discussion ou pull request qui ne le respecte pas, verrouiller une conversation, et suspendre ou exclure durablement une personne
dont le comportement est inapproprié, menaçant ou nuisible. Les raisons d'une décision sont expliquées quand c'est possible.

Ce code s'applique à tous les espaces du projet : ce dépôt GitHub (issues, discussions, pull requests) et les échanges publics où une
personne représente le projet.

## Signaler un comportement

Pour signaler un comportement inacceptable, écrivez à **contact@eukalyptus.app**. Tous les signalements sont examinés avec sérieux et
traités avec discrétion : l'identité de la personne qui signale reste confidentielle.

Pour une faille de sécurité, ne passez pas par cette adresse seule : suivez [SECURITY.md](SECURITY.md).

## Échelle des mesures

1. **Rappel** : un message privé ou public qui explique ce qui pose problème. Un simple rappel suffit le plus souvent.
2. **Avertissement** : pour un manquement répété ou plus grave, avec des conséquences si cela continue.
3. **Suspension temporaire** : interdiction d'écrire dans les espaces du projet pour une durée donnée.
4. **Exclusion définitive** : en cas de comportement durablement inapproprié ou de harcèlement.

## English summary

Participation in this repository (issues, discussions, pull requests) must be respectful and welcoming. Be patient and kind, accept
constructive criticism, and focus on what is good for the community. Harassment, insults, sexual content, publishing other people's
private information, spam and promotion are not acceptable. The project's author enforces this code and may edit, hide or delete
contributions, lock conversations, and suspend or ban people. To report unacceptable behavior, write to **contact@eukalyptus.app**;
reports are handled discreetly. For security vulnerabilities, see [SECURITY.md](SECURITY.md).
